# Zivaro — The Art of Intelligence

Standalone creative homepage. HTML, embedded CSS and vanilla JavaScript; local Three.js, GSAP / ScrollTrigger, D3 and TopoJSON. No npm, framework, compilation or build step.

## Run

From the repository root:

```sh
python3 -m http.server 4173 --bind 0.0.0.0 --directory zivaro-final-html-prototype
```

Open the server on port 4173. Deploy the contents of this directory directly to static hosting, retaining the `assets` directory.

## Experiences

Eleven chapters: layered 3D ribbon, signal transformation, generated editorial healthcare photography, healthcare/B2B switcher, ten-discipline network explorer, scroll-separated 3D analytical terrain, three interactive chart states, accurate regional map, editorial accordions, closing composition and footer. Enquiry controls download a local text brief; nothing is submitted or stored remotely.

## Validation

Chromium at 1920×1080, 1440×900 and 390×844: no horizontal overflow, photograph loaded, both WebGL canvases rendered, geographic geometry loaded. Domain switch, research selection, chart modes, regional selector and brief download passed; no JavaScript page errors. Reduced-motion rendering was exercised. Native semantic controls and keyboard tab navigation are included.

## Known limitations and asset sources

- The official brand site was inaccessible (network policy returned 403), and no original logo or brand-content document was supplied. Colors use the brief's fallback palette. The uppercase typographic identifier is provisional, **not the original logo**; replace it with the approved brand asset before production.
- Photography is AI-generated for this prototype and labeled accordingly; no real employee or company facility is implied.
- All chart data is synthetic and explicitly illustrative. Map markers show market context, not offices or confirmed facilities. Natural Earth country geometry is bundled through world-atlas 2.0.2 (public-domain geographical data).
- Local library distributions: Three.js 0.160.1 (MIT), GSAP / ScrollTrigger 3.12.5 (see bundled license headers and GSAP licensing), D3 7.9.0 (ISC), TopoJSON client 3.1.0 (ISC). Distribution license notices remain intact.
- Fonts: DM Sans and Cormorant Garamond via Fontsource (SIL Open Font License). See assets/OFL files.
